Travel Planner: v2 visual refresh

These are sample screens for the redesign. They show the target look: colour, type, spacing, elevation and layout. Every element shown already exists in the app; the mockups add no feature, change no copy and need no API change. Read them with UI-UX-REDESIGN.md, which has the exact token values and rules. PNG copies of each screen are in screens/.

01

Design system sheet

  • Tokens: see spec §4. Keep all existing token names; values marked "update" change.
  • Page is tinted #f8fafc; cards are white with --shadow-sm.
  • Teal is for actions and selection only. Coral accent is only for highlight badges.
  • Restyle existing classes in index.css; don't rename them.

My trips /

  • Header: logo mark plus "Travel Planner", pill nav, current section in teal. All links stay visible; there is no "Menu" button.

  • "New trip" is the one primary action.

Book trip drawer (BookTripDrawer); drawers and modals in general

  • Desktop: slides in from the right, 440px wide, --shadow-lg, sticky footer for actions. Phone: bottom sheet with a grab handle.
  • A checklist summary: chosen items have a green tick, unchosen items are muted.
  • Modals (delete, remove, share) are centred with radius 24. Only confirmations use a danger button.
  • The page behind stays visible under a 45% slate scrim.

Empty, loading and error states (also 404 and the local inbox)

  • Empty state: a sand circle with an icon, an H2, one muted line and one primary button. Existing text is kept ("No trips yet").
  • Skeleton .sk-card matches the real card shape (media, 2 lines, price stub) with a soft shimmer.
  • Error: .alert-danger with a title and next step plus a Retry button. The 404 page uses the same circle pattern.
  • Local inbox: a mail-client layout with a "Local mode" info banner.
